# Omnia — Universal AI Engineering, Design & Security System

Omnia packages strict Anti-AI High-Craft Design rules, Pre-Launch Security (50-Point Audit), Production Conversion & Legal Compliance, Universal Engineering Reliability, and 13 curated skills into one portable repository that works across **every AI coding agent**.

## What Is Included

- **Global Rule Files** (identical portable rules formatted for each tool):
  - `GEMINI.md` (Google Antigravity / Gemini CLI)
  - `CLAUDE.md` (Claude Code)
  - `AGENTS.md` (OpenAI Codex, OpenCode, Windsurf, Zed, universal standard)
  - `.cursorrules` (Cursor)
- **13 Curated Skills** (`skills/`):
  - `omnia` — Unified master meta-skill embedding all core pillars + skill index
  - `craft-design` — Anti-AI design, 60/30/10, Emil Kowalski motion physics, Taste Skill, 20 UX/Motion laws
  - `vibe-security` — Critical 7 non-negotiables & 50-point pre-launch security/legal audit
  - `engineering-reliability` — Async race conditions, iOS/Android quirks, Windows locking, DB/cents math, real-user edge cases
  - `fullstack`, `ui-ux-pro-max`, `humanizer`, `caveman`, `hyperframes`, `herk-edit-kit`, `remotion-best-practices`, `seo-audit`, `copywriting`

## Install on Any AI Agent

### 1. Universal Skills CLI (Claude Code, Cursor, Codex, Windsurf, Antigravity)
```bash
npx skills add <YOUR_GITHUB_USERNAME>/omnia --global
```

### 2. Google Antigravity / Gemini CLI
Copy `GEMINI.md` and `skills/` into your user config directory:
- **Windows**: `C:\Users\<YOU>\.gemini\config\`
- **macOS / Linux**: `~/.gemini/config/`

### 3. Claude Code
Copy `CLAUDE.md` and `skills/` into `~/.claude/` (global) or into the root of any project.

### 4. Cursor
Copy `.cursorrules` and `skills/` into your project root (or paste `.cursorrules` into Cursor Settings -> Rules).

### 5. OpenAI Codex / Windsurf / OpenCode
Copy `AGENTS.md` and `skills/` into your project root (or `~/.codex/` for Codex global).

### 6. ChatGPT / Claude.ai Web (Custom GPT or Claude Project)
Upload `skills/omnia/SKILL.md` to Project Knowledge / Custom Instructions.
